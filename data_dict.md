# Data Dictionary

## Target and Time Features

| Column | Description |
|---|---|
| timestamp | 15-minute timestamp |
| NLDC_DEMAND | India electricity demand target |
| hour | Hour of day, 0–23 |
| minute | Minute within hour: 0, 15, 30, 45 |
| day_of_week | Day of week, Monday=0 to Sunday=6 |
| day_of_month | Day of month |
| month | Month number |
| is_weekend | 1 for Saturday/Sunday, otherwise 0 |

---

## Delhi Weather

| Column | Description |
|---|---|
| delhi_T2M | Temperature at 2 meters, °C |
| delhi_RH2M | Relative humidity at 2 meters, % |
| delhi_SOLAR | All-sky surface shortwave downward irradiance, Wh/m² |
| delhi_WS10M | Wind speed at 10 meters, m/s |
| delhi_PRECIP | Corrected precipitation, mm/hour |
